# 人脸识别独立服务 · 部署费用测算

> 基于本仓库 InsightFace buffalo_s/l + ONNX Runtime 1:N 能力拆分估算。币种：人民币（¥）。价格为 2026 年国内云/人力公开行情量级，非正式报价。

`buffalo_s 可纯 CPU` · `无活体 / 无 1:1 API` · `尚未独立微服务`

---

## 一句话结论

> 做成「人员底库 + 识别 API」并上线：一次性拆分约 **¥1.5万–6万**；长期运行推荐生产 CPU 约 **¥800–2,000/月**。GPU 非刚需，仅高并发（约 >15–30 QPS 持续）再上。比 Azure Face API 按次计费更适合底库常驻、自控数据场景。

### 关键数字速览

| 指标 | 量级 |
|------|------|
| 一次性拆分交付 | **¥1.5–6万** |
| 试点上线首年（低配） | **¥0.4–1.2万** |
| 生产 CPU 首年运维量级 | **¥1–2.5万** |
| GPU / 双活首年量级 | **¥3–8万+** |

## 现有能力边界（费用相关）

| 能力 | 现状 | 对费用的影响 |
|------|------|--------------|
| 检测 + ArcFace 特征 | 已有 | 主算力；buffalo_s 可 CPU |

| 陌生人告警 | 依赖平台告警模块 | 独立服务需自带或外接 |

## 一次性费用（拆服务 + 上线）

| 工作项 | 人天（估） | 费用量级（¥） | 说明 |
|--------|-----------|---------------|------|
| 抽 API：enroll / recognize / persons | 5–10 | 8千–2万 | 从 face.py + gallery + InsightFace 段剥离 |
| 鉴权（API Key/JWT）+ 限流 + 日志 | 3–5 | 5千–1万 | 对外部署刚需 |
| Docker / Compose + 部署脚本 | 2–4 | 3千–8千 | 仓库当前无容器方案 |
| 压测与阈值标定（threshold） | 2–3 | 3千–6千 | 按业务误识/漏识调优 |
| 监控告警 + 备份 | 2–3 | 3千–6千 | 进程/磁盘/延迟 |
| 可选：1:1 / 活体 | 8–20+ | 1.5万–4万+ | 超出当前代码范围 |

按国内中级后端日薪约 ¥1,500–2,500 折算。内部自研取下限；外包交付取上限。

## 月度运行费用（自建）

量级：国内公有云按量 / 包年折月。含计算、RDS、对象存储、带宽、域名证书粗估；不含研发薪资。

### 月费用量级示意（千元）

```text
试点 CPU   ████░░░░░░  ~0.45
生产 CPU   ████████░░  ~1.2
生产 GPU   ████████████████░░░░  ~3.5
双活 HA    ████████████████████████████  ~6.5
```

| 档位 | 规格建议 | 适用负载 | 月费用（¥） | 年费用约（¥） |
|------|----------|----------|-------------|---------------|
| 试点 CPU | 2–4 核 / 8GB + 小 RDS | 底库 ≤500人，偶发识别 | 300–800 | 0.4–1.0万 |
| 生产 CPU | 4–8 核 / 16GB + RDS | 底库千人级，数路摄像头抓帧 | 800–2,000 | 1.0–2.5万 |
| 生产 GPU | T4/L4 级 + CPU 网关 | 持续高 QPS / buffalo_l | 2,500–5,000 | 3–6万 |
| 双活 HA | 双实例 + LB + 备份 | 可用性要求高 | 4,000–8,000+ | 5–10万+ |

### 推荐默认：生产 CPU + buffalo_s

与项目设计一致（README：纯 CPU 可跑；seed 标 buffalo_s 为 CPU 友好）。单路摄像头前端隔帧抓取时，QPS 通常很低（约 1–5），CPU 足够。

**首年现金流出粗算：** 拆分交付 ¥2–4万 + 运行 ¥1–2万 ≈ **¥3–6万**

### 何时上 GPU

持续识别 QPS > 15–30，或强依赖 buffalo_l、多路高帧率服务端解码。

云 T4 量级约 ¥2–4/小时；7×24 常开才会到「生产 GPU」月费档。

## 按调用量粗算（自建边际成本）

| 月调用量 | 自建边际成本 | 对比 Azure Face ~$1/千次 |
|----------|--------------|---------------------------|
| 1 万次 | ≈固定月费摊薄（几分/次量级） | 约 ¥70（按汇率粗算） |
| 10 万次 | 仍接近固定月费 | 约 ¥700 |
| 100 万次 | CPU 档仍可能更便宜 | 约 ¥7,000；自建更有利 |
| 底库存储 | embedding 极小 + 登记图 OSS | Face Storage 另计 |

> **选型提示**  
> 调用少、要免运维 → 可考虑云厂商 Face API。底库常驻、数据不出域、调用稳定 → 自建 InsightFace 服务通常更省且可控。本项目已具备自建核心代码。
