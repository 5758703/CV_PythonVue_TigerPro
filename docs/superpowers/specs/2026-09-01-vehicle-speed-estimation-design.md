# 行驶车辆测速优化设计

## 目标

修正车辆测速对离线处理耗时的依赖，使视频文件按媒体时间轴测速；将测速历史与轨迹展示解耦；以车辆底边中心作为道路接触点；提供稳健的速度估计、局部比例标定和双线测速，同时保持现有接口兼容。

本功能用于工程监控和速度趋势分析，不声明满足执法计量要求。

## 范围

本次修改车辆追踪页面、车辆路由和 `vehicle_track` 服务。保留现有 YOLO、ByteTrack、车牌 OCR、区域计数和结果视频流程。

本次不实现完整相机内参标定、镜头畸变校正或多摄像机测速。四点道路单应性作为可选增强：后端支持标定参数时使用，前端先提供双线标定这一可操作主流程。

## 测速模式

### 局部比例模式

兼容现有 `metersPerPixel`。车辆位置使用检测框底边中心 `(cx, y2)`。系统保存独立的短测速历史，不再因“运动轨迹”开关改变测速窗口。

速度由历史区间速度的中位数得出，再应用指数平滑。无效时间差、非有限值、异常跳点和超过上限的样本不参与计算。

### 双线模式

用户绘制测速线 A 和测速线 B，并输入两线之间的实际道路距离。相同 Track ID 首次依次穿过两条线时，使用穿线的媒体时间差计算区间平均速度。逆向穿越同样支持，穿越状态按 Track ID 隔离。

双线结果优先于局部比例结果；车辆尚未完成双线穿越时可显示局部比例估计，若未配置比例则显示“等待通过测速区”。

## 时间语义

- 视频文件：每帧显式传入 `frame_index / fps`，FPS 无效时回退 25。
- 实时帧：使用服务端 `time.monotonic()`；API 可接收客户端采集时间，但本轮不依赖不可信的浏览器墙钟。
- 服务层不得在已提供时间戳时调用 `time.time()`覆盖它。
- 同一轨迹出现时间倒退、重复时间或长时间中断时，重置该轨迹的测速历史。

## 数据结构

`VehicleSession` 新增：

- `speed_history`：每个 Track ID 的短窗口道路接触点与时间。
- `speed_ema`：每个 Track ID 的平滑速度。
- `speed_gates`：双线穿越状态、起始时间和方向。

原有 `track_history` 仅用于轨迹绘制和越线/区域统计，保持兼容。

每个检测结果继续输出 `speedKmh`，并新增：

- `speedSource`：`scale`、`double-line`或`null`。
- `speedQuality`：`warming-up`、`estimated`、`measured`或`invalid`。

## 接口

现有字段保持有效：

- `enableSpeed`
- `metersPerPixel`

新增可选字段：

- `speedMode`：`scale`或`double-line`。
- `speedLineA`、`speedLineB`：归一化线段坐标。
- `speedDistanceM`：两线实际距离。
- `speedMaxKmh`：异常速度上限，默认 240。

参数不完整时安全回退到局部比例模式；局部比例也缺失时不生成数字速度。

## 前端交互

车辆任务配置中的测速设置移入独立区域：

- 开关“车辆测速”。
- 方法选择：“双线标定（推荐）”和“局部米/像素”。
- 双线模式输入实际距离，并在现有首帧画布上依次绘制 A、B 两条测速线。
- 局部比例模式保留米/像素输入，并明确提示该值需要针对当前分辨率与道路区域标定。
- 结果标签区分“区间实测”和“比例估算”。

测速线与原有计数线相互独立，区域计数不影响测速配置。

## 错误处理

- FPS 为零、负数、NaN或超过 240 时回退 25。
- 距离、比例或时间差不合法时返回空速度，不抛出整帧错误。
- Track ID 跳变只影响对应车辆，不中断任务。
- 双线顺序异常、重复抖动穿线通过状态机去重。
- 速度超过配置上限时丢弃该样本，并输出 `speedQuality=invalid`。

## 测试

后端单元测试覆盖：

1. 离线视频速度只由帧号与 FPS 决定，不受处理耗时影响。
2. 底边中心而非检测框中心进入测速历史。
3. 轨迹显示开关不改变测速窗口。
4. 中位数过滤异常跳点，EMA平滑正常样本。
5. 双线正向、反向、重复穿越和无效距离。
6. 非单调时间、轨迹中断及速度上限。
7. 旧请求只传 `metersPerPixel` 时仍可工作。

前端通过生产构建验证模板与参数绑定；后端运行新增测速测试及现有车辆区域测试。

## 验收条件

- 同一段视频在快慢不同的机器上得到相同速度序列。
- 开关运动轨迹不会改变测速结果。
- 双线模式用已知距离和媒体时间计算区间速度。
- 未标定时页面不显示具有误导性的默认真实车速。
- 现有车辆检测、OCR、计数和结果下载保持可用。
