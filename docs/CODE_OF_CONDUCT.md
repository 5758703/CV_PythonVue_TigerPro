# 行为准则（CODE OF CONDUCT）

## 我们的承诺

为建设开放、友好的社区，我们承诺：无论年龄、体型、可见或不可见的残障、族裔、性别特征、性别认同与表达、经验水平、教育、社会经济地位、国籍、外貌、种族、宗教或性取向如何，参与本项目的每个人都应免于骚扰。

## 我们的标准

**鼓励的行为示例：**

- 使用欢迎与包容的语言
- 尊重不同观点与经验
- 优雅地接受建设性批评
- 关注对社区最有利的事情
- 对其他社区成员表示同理心

**不可接受的行为示例：**

- 使用性化语言或意象，以及不受欢迎的性关注或挑逗
- 挑衅、侮辱/贬损性评论，以及人身或政治攻击
- 公开或私下骚扰
- 未经明确许可发布他人私人信息（如住址、邮箱、人脸/生物特征数据）
- 其他在专业场合可被合理视为不当的行为

## 执行责任

项目维护者有权删除、编辑或拒绝不符合本准则的评论、提交、代码、wiki 编辑、Issue 等，并在适当时通报违规原因。

严重或反复违规者，维护者可暂时或永久封禁其参与项目的权限。

## 报告方式

可通过 [SECURITY.md](./SECURITY.md) 中的私密渠道，或直接联系 Maintainer [@5758703](https://github.com/5758703) 报告滥用行为。  
所有投诉将被审查与调查，并视情况采取必要措施。维护者有义务对事件报告人保密。

## 适用范围

本准则适用于所有项目空间，也适用于个人在公共空间代表项目时的行为（例如使用官方邮箱、社交媒体账号或作为指定代表参加线上/线下活动）。
